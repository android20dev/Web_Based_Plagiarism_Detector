Web Based Plagiarism Detector

Project Overview

Web Based Plagiarism Detector is a web application designed to identify similarities between text and documents. It helps students, teachers, and researchers check content originality.

Objectives

- Detect duplicate and similar content.
- Compare text and uploaded documents.
- Display plagiarism results in an easy-to-understand format.
- Help users improve content originality.

Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Java, Spring Boot
- Database: MySQL
- Tools: IntelliJ IDEA
- Code Hosting Platform: GitHub 

Key Features

- Text comparison
- Document upload and checking
- Similarity percentage
- Highlighted matching content
- Plagiarism report

Algorithms Used

- Jaccard Similarity
- TF-IDF
- Cosine Similarity
